# 수익률 · 물가상승률 기본값 (근거 포함)

> §7 몬테카를로 예산 산출용 기본 가정값. 화면에 노출하고 사용자가 조정 가능하게 한다.
> 대상 사용자가 목돈(전세 보증금, 노트북 등) 단기 목표를 위해 저축하는 20대라는 점을 고려해,
> 공격적인 100% 주식 수익률이 아니라 보수적인 분산 포트폴리오 기준을 기본값으로 삼는다.

## 수익률 변동성 (분포)

- **기본 평균 수익률: 연 7%**
- **기본 표준편차: 연 9%** (몬테카를로 샘플링 시 정규분포 `N(7%, 9%)` 가정)
- 조정 가능 범위 제안: 평균 3~10%, 표준편차 5~15%

**근거**: 주식 60% / 채권 40%로 구성된 대표적인 "보수적 분산 포트폴리오(60/40)"의 초장기(1793~2026, 약 234년) 백테스트 결과, 연평균 수익률(CAGR) 7.34%, 표준편차 9.11%. 100% 주식(S&P 500 등)의 장기 평균(~10%, 표준편차 15~16%)보다 변동성이 낮아, 단기 목표를 가진 사용자에게 더 적합한 기본 가정으로 채택.
출처: [LazyPortfolioETF – Stocks/Bonds 60/40 Portfolio](https://www.lazyportfolioetf.com/allocation/stocks-bonds-60-40/)

## 물가상승률

- **기본값: 연 2%**
- 조정 가능 범위 제안: 1~4%

**근거**: 한국은행이 1998년부터 운영 중인 물가안정목표제의 공식 목표치가 소비자물가상승률(전년동기대비) 기준 연 2%(2016년 2.5~3.5%에서 하향 조정). 최근 실제 소비자물가상승률도 2%대 초반으로 목표치에 근접해 있어, 장기 기본 가정으로 적절.
출처: [한국은행 – 물가안정목표제(inflation targeting)란 무엇인가?](https://www.bok.or.kr/portal/bbs/P0002897/view.do?nttId=226036&menuNo=200788&pageIndex=1)
