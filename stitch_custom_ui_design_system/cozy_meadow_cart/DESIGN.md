# DESIGN SYSTEM: 동물의 숲/레트로 캐주얼 감성 장바구니 정리 서비스 (Cart Organizer)

## Concept & Tone
- 편안하고 둥글둥글한 2D 캐주얼 게임 (동물의 숲 + 레트로 플래시 감성)
- 절약/잔소리 금융 앱이 아닌, 기분 좋고 쾌적한 쇼핑 정리 워크스페이스
- 표절 없이 독창적인 일러스트레이션 풍, 부드러운 유기적 형태

## Color Palette
- Background: `#FAF6EC` (따뜻한 밀크 크림)
- Surface/Card: `#FFFFFF` / `#FFFDF9` with soft warm cream border
- Primary Accent: `#8FB98A` (편안한 세이지 그린 - 적극 지원, 완료, 긍정 버튼)
- Secondary Accent: `#E89B7D` (따뜻한 테라코타 피치 - 포인트, 목표 하이라이트)
- Warning/Over-budget: `#E28768` (경고 빨강 금지, 부드러운 테라코타 코랄 톤)
- Text Main: `#5C4A3A` (따뜻한 코코아 브라운, 순검정 금지)
- Text Sub: `#8D7B6D` / `#A69888` (부드러운 모카 그레이)
- Border: `2px solid #D6C9B0` or `#E2D7C3`
- Highlight Yellow: `#FBE49D` (치즈 옐로우 - 뱃지, 코인 느낌)

## Typography & Geometry
- Font: Rounded Gothic ('NanumSquareRound', 'Gaegu', 'Pretendard', system rounded-sans)
- Border Radius: Cards 20px, Buttons full pill (9999px), Inputs 16px
- Outlines: 2px solid outlines, minimal drop shadow, distinct tactile button feel (slight pressed effect)
- Spacing: 넉넉한 숨통, 포근한 여백

## Components
- Pill Buttons with slight bottom border/shadow for cute toy-like tactile feel
- Drag-and-drop styled item cards with neat thumbnail, item title, price pill, and reason tag
- Fixed bottom runner bar with original cute mascot running towards goal
- Floating dialogue bubbles with cute companion mascot instead of dry machine AI
